# 번역 대기 목록

## 원본 언어

매뉴얼의 원본은 한국어(`docs/manual/ko`)입니다.
영어(`en`), 일본어(`ja`), 중국어(`zh`)는 한국어 원본을 옮긴 번역본입니다.

규칙이 바뀌면 한국어 페이지를 먼저 고칩니다.
번역본에 아직 옮기지 못한 내용은 이 문서에 페이지와 절 단위로 적습니다.

이 문서에 적힌 번역본 페이지에는 맨 위에 안내를 둡니다.
안내는 그 페이지가 한국어 원본보다 오래되었다는 사실과 같은 한국어 페이지의 링크를 담습니다.
번역을 마치면 해당 페이지의 안내와 이 문서의 항목을 함께 지웁니다.

## D56 이후 한국어 원본 변경 반영(2026-11-25 네 언어에 반영 완료)

D56(예제를 테스트 사본으로 교체)부터 2026-11-25까지의 한국어 원본 변경을 영어, 일본어, 중국어에 반영했습니다. 남은 대기 항목은 없습니다.
쪽마다 현재 한국어판과 절 단위로 비교해 다시 옮겼고, 번역 검사 도구(`check_translation.py`)는 세 언어 모두 문제 0건입니다.

반영한 변경의 범위는 다음과 같습니다.

- D56 예제 교체와 출처 링크, 한국어 문구 정리, D54 조인 판정, 정렬 API(D59), LIKE(D60), 값 삼항·CASE WHEN(D61·D62)
- `count(컬럼)`·`count(o -> o)`·엔티티 쿼리의 `distinct()`(D67·D69), 조인 결과와 `toSet()`(D68), 엔티티 `select`(D70), 조인 10개(D71), `orderBy` 없을 때 정렬 없음(D73)
- Maven 좌표 `io.github.lambdaql`과 버전 0.0.2, 저장소 주소 `github.com/lambdaql/lambdaql`
- 컴파일러가 검사하는 내용의 설명 삭제, 본문의 규칙 번호 삭제(규칙 정리 표와 목차는 유지), 예제 맨 위의 import 줄
- Kotlin `it.cnt != 1` 설명 수정(9.15, 10장 G1)

번역본의 용어: 절 끝 출처 줄은 영어 "Example code:", 일본어 "コード例:", 중국어 "示例代码："를 씁니다. 11장의 메시지 표는 각 언어의 메시지 파일(`LqlMessages_*.properties`) 문구를 씁니다.

## D54·D55 반영(2026-11-23, `feature/unified-boot`)

다음 변경을 한국어 원본과 영어, 일본어, 중국어에 함께 반영했습니다. 남은 대기 항목은 없습니다.

1. D54: Kotlin `?.`·`!!`에 따른 where 조인 구분(개요, Kotlin 02·03·04·07·09·10·README, 11장 `LQL-5014`)
2. PostgreSQL·MySQL 반영으로 바뀐 `LQL-5001`·`LQL-5007` 메시지와 설명, upsert 주석
3. D55: Spring Boot 3·4 동시 지원(새 공통 페이지 13장, 02·10·11·12장과 README의 버전·아티팩트·데이터베이스 표기)

코드 블록은 `.claude/tools/docs/sync_code_blocks.py <기준 커밋> <언어>`로 먼저 맞췄습니다. 한글이 없는 블록은 그대로 복사하고, 한글 주석이 있는 블록은 바뀐 줄만 옮깁니다.
Kotlin 09장의 "네 가지 결정"은 표에 D54가 더해져 네 언어 모두 "다섯 가지"로 고쳤습니다.

## Boot 4 브랜치 반영(2026-11-19, `feature/boot4`)

다음 변경을 한국어 원본과 영어, 일본어, 중국어에 함께 반영했습니다. 남은 대기 항목은 없습니다.

1. U9 연관 경로 서브쿼리의 FK 표기 `fk(e0.customer)`
2. Oracle 함수 기반 인덱스의 숫자 변환(`FN(TO_NUMBER(COLUMN))`)
3. 클래스 파일 읽기: Java 24 이상은 `java.lang.classfile`(D52)

## 한국어 원본 다듬기(2026-11-19 네 언어에 반영 완료)

번역 중 발견한 문구 문제 9건을 한국어 원본과 영어, 일본어, 중국어에 함께 고쳤습니다. 남은 대기 항목은 없습니다.

고치지 않은 것과 이유는 다음과 같습니다.

- 08장 `pass_procedure_paramater_names`: Hibernate 6.6.5의 설정 이름(`hibernate.query.pass_procedure_paramater_names`, `QuerySettings`)이 이 철자여서 문서를 그대로 둠
- README 첫 앵커 `lambdaql-user-manual-english`: 링크가 쓸 수 있어 이름을 바꾸지 않음
- 영어 번역본: 영어 제목은 `Insert ... select`, `Group by`, `Having`처럼 문장형 대문자이고 Java와 Kotlin이 이미 같아 제목을 바꾸지 않음
- 3.5, 6.6, `BigDecimal` 제목의 앵커: 번역본은 제목 자체가 같은 id를 만들어 명시 앵커를 넣지 않음(한국어 원본에만 명시 앵커 추가). 일본어와 중국어 Kotlin 06의 6.5는 제목을 Java에 맞추면서 id가 달라져 명시 앵커를 추가함
